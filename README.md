## About me

I started coding as a kid. My first real users were gamers: in 2021 I was writing Lua for FiveM roleplay servers, then Discord bots and paid services for the people running those communities. One of them, **FileSafety**, a licensing platform for script developers, grew into a real business. I built it, ran it and sold it.

That's where I learned to ship things people pay for and keep them running. These days I build for businesses, from an empty repo to production: database, API, web, mobile and the 3D scene in the browser.

## Things I've built

- 🧠 [**salesbrain-skill**](https://github.com/devbyghaith/salesbrain-skill): evidence-graded sales judgment for AI agents
- 🔐 [**FileSafety**](https://github.com/devbyghaith/FileSafety): licensing & activation SaaS for script developers (2021–22, sold)
- 📦 [**FromHost**](https://github.com/devbyghaith/FromHost): licensing & file hosting for FiveM developers (2022)
- 🔄 [**Syncord**](https://github.com/devbyghaith/Syncord): Discord member backup & restore SaaS (2022)
- 🛡️ [**Guard**](https://github.com/devbyghaith/Guard): Discord anti-nuke protection bot (2022)
